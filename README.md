This repository provides all code needed to reproduce the results and figures in 

Peterson, C. M., & Matthews, J. W. (2026). Comparing diversity‑carbon tradeoffs across reforestation strategies at a long-term floodplain experiment. Ecological Engineering, 233, 108125. https://doi.org/10.1016/j.ecoleng.2026.108125

All data are archived at https://doi.org/10.5281/zenodo.17226674 and should be cited if used.
